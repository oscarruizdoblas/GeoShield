# Padova Gazebo scenario

- `worlds/padova.sdf`: world used by PX4 SITL (generated by `code/python/build_world.py`).
- `models/padova_ground/`: ground plane with the Padova map texture (`code/python/make_texture.py`).
- `launchers/`: start the SITL and the Gazebo window.

`bash code/sync_wsl.sh` installs the world and the model into the PX4 tree if they are missing. The scene is a visual base (map texture, red no-fly zones, simple grey buildings); it does not model the buildings precisely or simulate collisions.
